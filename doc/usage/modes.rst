PAWIAN execution modes
======================

.. note::
  See original Wiki page `here
  <https://panda-wiki.gsi.de/foswiki/bin/view/PWA/ExecutionModes>`__.


.. option:: pwa

  Perform a PWA on a single machine, using Minuit as minimizer.


.. option:: qaMode

  QA-mode / histogramming.


.. option:: qaModeSimple

  Simplified and memory-saving :option:`qaMode` for plotting histograms and
  extracting goodness of fit criteria.


.. option:: spinDensity

  Calculate spin density matrix elements.


.. option:: server

  Act as a server for a client/server-based analysis, use Minuit as minimizer.


.. option:: client

  Act as a client for a client/server-based analysis.


.. option:: evo

  Perform a PWA on a single machine, use the evolutionary minimizer.


.. option:: evoserver

  Act as a server for a a client/server-based analysis, use the evolutionary
  minimizer.


.. option:: gen

  Generate Monte-Carlo events ― phase space distributed or with a model.


.. option:: dumpDefaultParams

  Generate a file with default parameters.
